# Hola, soy Roberto Arregui Rosas

## Full Stack Developer

Soy desarrollador Full Stack con experiencia en el desarrollo de aplicaciones web y móviles, trabajando principalmente con **Angular, React, TypeScript, Node.js y NestJS**.

He participado en el desarrollo de plataformas administrativas, aplicaciones móviles, integración de APIs REST, autenticación y roles, dashboards, manejo de bases de datos y servicios en la nube.

También cuento con experiencia colaborando en equipos ágiles, participando en planificación, seguimiento de tareas, resolución de bloqueos y entrega de funcionalidades.
